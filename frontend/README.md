## Usage

Dependencies are managed from the repository root with Bun workspaces:

```bash
bun install
```

### Learn more on the [Solid Website](https://solidjs.com) and come chat with us on our [Discord](https://discord.com/invite/solidjs)

## Available Scripts

Run these from this directory or use `bun --filter @ariadm/frontend <script>` from the root:

### `bun run dev`

Runs the app in the development mode.<br>
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `bun run build`

Builds the app for production to the `dist` folder.<br>
It correctly bundles Solid in production mode and optimizes the build for the best performance.

### `bun run typecheck`

Type-checks the project with Bun's native TypeScript checker.

The build is minified and the filenames include the hashes.<br>
Your app is ready to be deployed!
